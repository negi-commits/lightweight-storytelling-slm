# 🧸 Lightweight Storytelling SLM for Toddlers

A **GPT-inspired Small Language Model (SLM)** designed for **automatic toddler story generation (ages 3–4)** using the **TinyStories dataset**.

## 📌 Problem Statement

Traditional AI storytelling systems are often computationally expensive and not optimized for early childhood learning. The goal of this project was to explore:

**Can a lightweight 10–15M parameter language model generate coherent, child-friendly stories?**

## 🚀 Project Overview

This project introduces a compact storytelling SLM that generates **simple, imaginative, and age-appropriate stories** from minimal prompts.

The model focuses on:

* Child-friendly storytelling
* Coherent story generation
* Lightweight architecture
* Educational AI applications

## ⚙️ Model Architecture

* **Transformer Layers:** 6
* **Attention Heads:** 6
* **Embedding Size:** 384
* **Context Window:** 128 Tokens
* **Tokenizer:** GPT-2 (`tiktoken`)
* **Optimizer:** AdamW

## 📊 Challenges Faced

* Maintaining coherence with limited parameters
* Avoiding repetitive text generation
* Balancing simplicity and creativity
* Context window limitations

## 🛠 Tech Stack
